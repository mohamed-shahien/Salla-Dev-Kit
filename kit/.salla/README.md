# .salla

هذا المجلد يحتوي قواعد التشغيل الداخلية للـ workflow kit.

الهدف منه أن يكون مرجعا سريعا ومنظما لأي agent قبل تعديل ثيم سلة.

## الملفات

- `workflow.md`: خطوات التنفيذ من الطلب حتى التسليم.
- `templates/`: قوالب spec-kit لكل مرحلة.
- `component-blueprint.md`: قالب مواصفات مكون قبل التنفيذ.
- `component-checklist.md`: قائمة تحقق خاصة بالمكونات.
- `quality-gates.md`: بوابات الجودة النهائية.
- `naming-conventions.md`: قواعد التسمية والمسارات.

## طريقة الاستخدام

عند أي طلب تعديل:

1. `specify`
2. `clarify`
3. `plan`
4. `tasks`
5. `analyze`
6. `implement`
7. `review`

استخدم القوالب داخل `templates/` لإنتاج ملفات كل مرحلة.
