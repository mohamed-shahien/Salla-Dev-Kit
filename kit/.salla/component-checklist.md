# Component Checklist

استخدم هذه القائمة عند إنشاء أو تعديل مكون.

## قبل التنفيذ

- [ ] تم تحديد هل التغيير عام أم خاص بمكون.
- [ ] إذا كان المكون جديدا، تم إنشاؤه في Salla Partners.
- [ ] تم الحصول على `key` الحقيقي من سلة.
- [ ] تم الحصول على `path` الحقيقي من سلة.
- [ ] تم تحديد ملف Twig الصحيح.
- [ ] تم تحديد ملف CSS الصحيح.
- [ ] تم تحديد هل يحتاج JS.

## `twilight.json`

- [ ] لم يتم تعديل إلا `settings` أو `components`.
- [ ] لم يتم إنشاء كائن مكون يدويا بدون Salla Partners.
- [ ] الإعدادات العامة وضعت في `settings`.
- [ ] الإعدادات الخاصة بالمكون وضعت في `fields`.
- [ ] الحقول لها `id` واضح و lowercase.
- [ ] الحقول لها `label` عربي واضح.
- [ ] القيم الافتراضية مناسبة.
- [ ] لم يتم تكرار إعداد عام داخل كل مكون.

## Twig

- [ ] أول سطر في المكون هو `{% set c = component %}`.
- [ ] كل المتغيرات lowercase.
- [ ] لا يوجد `<script>`.
- [ ] لا يوجد `<style>`.
- [ ] قراءة fields تتم من `c`.
- [ ] قراءة settings تتم من `theme.settings.get`.
- [ ] توجد fallbacks للقيم الاختيارية.
- [ ] تم استخدام المكونات المساعدة عند الحاجة.
- [ ] توجد empty state عند عدم وجود بيانات.

## CSS/SCSS

- [ ] CSS موجود في ملف الصفحة المناسب.
- [ ] يوجد تعليق المكون الإلزامي.
- [ ] لا توجد styles inline في Twig.
- [ ] تم استخدام CSS variables العامة عند الإمكان.
- [ ] التصميم responsive.
- [ ] لا توجد كروت داخل كروت بدون حاجة.

## JavaScript

- [ ] JS موجود في ملف منفصل داخل `services/home/` إذا كان للصفحة الرئيسية.
- [ ] لا يوجد JS inline داخل Twig.
- [ ] الاستدعاء في `home.js` عبر `lazyImportWhenExists`.
- [ ] selector يطابق كلاس موجود في HTML.
- [ ] init لا يعمل مرتين على نفس العنصر.
- [ ] لا يتم تحميل JS إذا لم يكن المكون موجودا.

## التسليم

- [ ] تم تشغيل build أو lint إذا كان متاحا.
- [ ] تم ذكر أي تحقق لم يمكن تشغيله.
- [ ] تقرير التسليم يذكر الملفات والسبب وطريقة الاستخدام.
